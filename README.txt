UNIVERSITAS SERUNI — WEBSITE MULTI-HALAMAN

STRUKTUR
- UniversitasSeruni.html : Beranda dan berita dengan pagination (10 berita per halaman)
- Tentang.html           : Profil, sejarah, timeline, dan pencapaian
- Fakultas.html          : Daftar fakultas, pencarian, filter akreditasi
- Kontak.html            : Email, telepon, dan jam operasional
- Lokasi.html            : Empat lokasi kampus, peta, dan tautan shuttle
- assets/css/styles.css  : Semua gaya tampilan bersama
- assets/js/berita-data.js : Data 105 berita dari HTML lama
- assets/js/main.js      : Navigasi, pagination, dan filter fakultas

CARA MENGGUNAKAN
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka UniversitasSeruni.html di browser. Tidak perlu file index.html.
3. Jangan memisahkan folder assets dari file HTML.

TAUTAN YANG DIPERTAHANKAN
- Setiap kartu fakultas tetap mengarah ke path persis seperti HTML lama (folder fakultas/...).
- Tautan "Peta dan jadwal shuttle bus antar kampus" tetap mengarah ke peta.html.
- Pastikan file detail fakultas dan peta.html yang sudah dimiliki sebelumnya tetap ditempatkan pada lokasi/path tersebut agar tautannya terbuka.

CATATAN
- Seluruh 105 berita yang terbaca dari HTML lama disertakan dan ditampilkan 10 berita per halaman.
- Urutan berita asli dipertahankan.
- Tidak ada file index.html dan tidak menggunakan gambar/logo merek di header.
- Data alamat, kontak, kampus, timeline, status akreditasi, serta href detail fakultas diambil dari file HTML lama.
