FAKULTAS TEKNIK — UNIVERSITAS SERUNI

STRUKTUR FILE
- teknik.html       : Halaman utama / Profil Fakultas
- sejarah.html      : Sejarah Singkat Fakultas
- organisasi.html   : Struktur Organisasi & Manajemen + Ruang Lingkup Keilmuan
- akademik.html     : Departemen + Fasilitas Akademik & Riset + Laboratorium & Pusat Riset
- riset.html        : Riset, Publikasi & Kolaborasi + Layanan Publik & Konsultasi + Alumni & Peluang Karir
- kontak.html       : Kontak & Lokasi
- assets/css/teknik.css : Stylesheet bersama
- assets/js/teknik.js   : Hamburger dan pencarian program studi

CARA MEMBUKA
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Jangan memindahkan file HTML keluar dari folder atau memisahkan folder assets.
3. Buka teknik.html dengan browser.
4. Gunakan menu navigasi untuk berpindah ke lima halaman lainnya.

CATATAN
- Tidak ada file index.html.
- Tidak ada logo grafis. Nama fakultas dan universitas ditampilkan sebagai teks.
- Konten pada bagian-bagian utama diambil dari HTML sumber yang diunggah.
- Fitur pencarian program studi, detail departemen buka-tutup, tombol Kirim Email, dan tautan telepon dipertahankan.
