# Website Pendidikan Vokasi Universitas Seruni

## Halaman
- `teknik.html` — halaman utama / profil
- `sejarah.html` — sejarah singkat
- `organisasi.html` — struktur organisasi dan ruang lingkup keilmuan
- `departemen.html` — 32 departemen, daftar program, fasilitas, laboratorium, dan pusat riset
- `riset.html` — riset, publikasi, kolaborasi, layanan, alumni, dan peluang karir
- `kontak.html` — kontak dan lokasi

Tidak ada file `index.html`. Buka `teknik.html` untuk memulai.

## Aset bersama
- `assets/css/style.css`
- `assets/js/main.js`

Seluruh halaman saling terhubung melalui navigasi desktop dan hamburger pada layar kecil. Halaman departemen dilengkapi fitur pencarian.
