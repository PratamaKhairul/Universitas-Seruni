WEBSITE FK-KMK UNIVERSITAS SERUNI

Isi paket:
- fk.html: halaman utama
- sejarah.html: sejarah fakultas
- organisasi.html: organisasi dan ruang lingkup keilmuan
- departemen.html: departemen, program studi, fasilitas, laboratorium, dan pusat riset
- riset.html: riset, layanan, dan alumni
- kontak.html: kontak dan lokasi
- assets/style.css dan assets/main.js: gaya visual dan interaksi bersama

Cara membuka:
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Pastikan folder assets tetap berada sejajar dengan seluruh halaman HTML.
3. Buka fk.html melalui browser.

Halaman departemen diperbarui dengan 180 program pada 33 departemen. Pencarian dan filter jenjang dapat digunakan bersama.
