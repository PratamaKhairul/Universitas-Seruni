# Portal Kurikulum Program Studi Geografi

Situs statis multi-halaman yang dapat dibuka langsung dari `geografikur.html`. Tidak ada `index.html` agar sesuai permintaan.

## Struktur
- `geografikur.html` — beranda / halaman awal
- `profil.html` — identitas, visi, misi, dan kompetensi
- `tentang.html` — pendekatan pembelajaran dan lingkup kajian
- `sejarah.html` — sejarah program studi dan linimasa
- `mata-kuliah.html` — katalog mata kuliah dengan pencarian, filter, dan ekspor CSV
- `kurikulum.html` — distribusi semester 1–8, simulasi SKS, dan ringkasan
- `riset-pengabdian.html` — tema riset dan pengabdian
- `assets/` — CSS, JavaScript, dan data katalog

## Menjalankan
Ekstrak ZIP, lalu buka `geografikur.html` di browser. Situs ini tidak membutuhkan server atau database untuk fitur inti.

## Catatan data dan akademik
1. Total rancangan semester 1–8 adalah 144 SKS (19 + 19 + 20 + 22 + 24 + 24 + 10 + 6).
2. Keterangan minimum 144 SKS, maksimum 164 SKS, dan batas masa studi 12 semester/6 tahun mengikuti brief pengguna. Simulasi di situs bersifat informatif, bukan validasi KRS.
3. Prefix kode GKWK, GLWK, GEWK, dan USWK berasal dari daftar pengguna. Nomor unik seperti `GEWK-101` dibuat sebagai **kode katalog usulan**, bukan kode resmi universitas.
4. Semester pilihan mengikuti daftar pengguna. `Pemodelan Geodesi untuk Kebencanaan` tidak memiliki semester pada sumber, sehingga ditandai belum ditetapkan.
5. Narasi visi, misi, profil lulusan, sejarah kelembagaan setelah tahun 2001, dan tema riset/pengabdian ditulis sebagai konten usulan profesional. Verifikasi dengan dokumen resmi Universitas Seruni sebelum dipublikasikan sebagai informasi institusional final.
6. Istilah "peminatan SIG PJ" diperjelas menjadi "Geospasial, SIG, dan Penginderaan Jauh"; penamaan ini dapat disesuaikan dengan nomenklatur resmi.
