WEBSITE FGIK UNIVERSITAS SERUNI

STRUKTUR FILE
- fgik.html          : halaman utama / profil fakultas
- sejarah.html       : sejarah fakultas
- organisasi.html    : struktur organisasi dan ruang lingkup keilmuan
- departemen.html    : departemen, fasilitas, laboratorium, dan pusat riset
- riset.html         : riset, publikasi, kolaborasi, layanan publik, alumni, dan karir
- kontak.html        : kontak dan lokasi
- assets/css/style.css : stylesheet bersama
- assets/js/main.js   : interaksi hamburger dan formulir

CARA MENJALANKAN
Ekstrak seluruh folder, lalu buka fgik.html melalui browser. Jangan memindahkan file HTML terpisah dari folder assets karena seluruh halaman menggunakan stylesheet dan JavaScript bersama.

CATATAN
- Tidak ada index.html. Halaman utama bernama fgik.html.
- Navigasi enam halaman dan menu hamburger sudah disiapkan.
- Tautan halaman departemen giw.html, iln.html, geo.html, tgeo.html, dan klt.html tetap dipertahankan dari situs asal; halaman tujuan tersebut perlu tersedia dalam folder yang sama agar tautannya aktif.
- Formulir pertanyaan saat ini hanya contoh front-end dan belum mengirim data ke server.
